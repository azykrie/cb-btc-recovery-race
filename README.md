A Python 3.13 paper trader for one-minute cbBTC bars. It buys deep deviations after a short recovery, sizes at 25% of cash, and uses time, stop and drawdown exits. The measured dev profit is small and does not establish an unseen-market edge. See RESULTS.md.

## Run it

```sh
python3 -P -s main.py
```
